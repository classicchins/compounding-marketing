## Decisions taken this session

1. **5 skills wired for v1.7** (vs. all 61): `copywriting`, `cold-email`, `positioning`, `paid-ads`, `icp-research`. Future releases roll out the read side incrementally. Schema is forward-compatible.
2. **Validator policy** for the new section: **soft warning, non-blocking**. Errors stay error-only; warnings print in a separate block. Lets the v1.7-v1.8 rollout continue without breaking the build on partial coverage.
3. **`/cm-compound` rewrite philosophy**: validate-and-reject, not silently-correct. Bad entries surface as errors. Append-only. Reverse-chronological. Frontmatter (`last_updated`, `entries_count`) updated on every write.
4. **Integration auto-detection split**: Phase 1 in v1.8 (detect, no skill behavior changes); Phase 2 in v1.9 (per-skill integration-aware paths). Avoids designing without user-data feedback on which integrations matter.
5. **v1.7 ships as its own release tag**, not folded into v1.8. (Open question — flagged in v1.8 brainstorm §6 "Open questions for decision" #6, awaiting your call.)
